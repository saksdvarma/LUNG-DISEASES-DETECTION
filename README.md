# 🫁 Lung Disease Detection (Deep Learning)
**CNN-based Classification of Lung Diseases from Medical Imagery.**

## 🌍 Real-World Impact
Timely and accurate detection of lung diseases is critical in clinical settings to improve patient outcomes. This project leverages deep learning to act as an automated second opinion for radiologists, identifying potential diseases from raw medical scans with high accuracy.

## 📊 Analytical Data & Key Metrics
- Modeled complex visual patterns in medical imagery to classify distinct lung diseases.
- Highly optimized for **precision and recall**, minimizing false negatives which are catastrophic in clinical diagnostics.

## ⚙️ Tech Stack & Architecture
- **Models:** Convolutional Neural Networks (CNNs)
- **Domain:** Deep Learning, Medical Imaging
- **Language:** Python

## 🧠 Technical Highlights
Designed a deep learning architecture capable of distinguishing subtle radiographic anomalies, focusing heavily on loss-function optimization to prioritize clinical recall.
